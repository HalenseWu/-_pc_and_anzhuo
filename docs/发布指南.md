# 发布指南（把项目放到 GitHub）

## 1. 建仓库

在 GitHub 新建一个空仓库（不要勾选 README / .gitignore / License），拿到地址，例如：

```
https://github.com/<你的用户名>/wuya-reader.git
```

## 2. 初始化并推送

在解压后的 `wuya/` 目录里执行：

```bash
git init
git add .
git commit -m "无涯阅读器：桌面版 0.21.0 + 安卓版 0.4.1"
git branch -M main
git remote add origin https://github.com/<你的用户名>/wuya-reader.git
git push -u origin main
```

> 仓库里已经带了 `.gitignore`，构建产物（`out/`、`release/`、`android/build/`、`node_modules/`、`assets/`）不会入库。

如果推送体积报错（超过 1GB 或单文件超 100MB）：

- 本仓库最大文件是 `mobile/app/android/app/src/main/jniLibs/arm64-v8a/libonnxruntime.so`（21MB），在限制内；
- 请确认没有把音色包（18–75MB 的 zip）或 `release/` 里的安装包提交进来。

## 3. 上传安装包与音色包（Releases）

1. 仓库页 → **Releases → Draft a new release**；
2. Tag 建议 `v0.4.1`，标题「无涯 0.4.1」；
3. 附件上传：
   - `Wuya-0.21.0-x64.exe`、`Wuya-0.21.0-portable.exe`
   - `Wuya-Mobile-0.4.1-debug.apk`
   - `Matcha-zh-baker.zip`、`Piper-zh_CN-huayan-x_low.zip`、`MeloTTS-zh_en-int8.zip`（可选）
4. 说明里写上 SHA-256（可选）与「首次运行 SmartScreen 提示」的说明。

在仓库的 `About` 里填一句简介，并把 **Releases** 与 **README** 里的下载链接对应起来。

## 4. 开源前的自查清单

- [ ] 仓库里没有个人路径、用户名、微信临时文件（本包已清理）；
- [ ] 没有个人音频样本（`参考语音/`、`参考图片/` 已排除）；
- [ ] `LICENSE` 与 `NOTICE.md` 中的第三方许可与实际依赖一致；
- [ ] 音色包未入库，README 里写清获取方式与许可提示；
- [ ] APK 只包含 arm64 架构，体积约 48MB。

## 5. 建议的仓库设置

- **Issues**：开启，模板可加「阅读问题 / 导入问题 / 朗读问题」；
- **Discussions**：可选，用于音色包分享；
- **Actions**：可选，加一条 `pnpm build` 的桌面构建检查；
- **Topics**：`novel-reader`、`epub`、`pdf`、`electron`、`capacitor`、`tts`、`offline`、`chinese`。
