# 更新日志

版本号规则：桌面版 `0.x.y`，安卓版 `0.x.y`（两条线各自独立递增）。

---

## 安卓版

### 0.4.1

- 朗读交互改版：点「听」只展开面板，点 ▶ 才开始朗读
- 新增「收起」→ 悬浮球，读中可随时展开/收起
- 修复：面板收起后没有浮球、读中再点「听」无处可点的问题

### 0.4.0

- 修复导入音色包卡死、按钮失效：改用 Capacitor 8 的 `@ActivityCallback`
- 导入过程上报进度（文件数/已解压体积）
- 取消选择文件后按钮立即恢复可用

### 0.3.9

- 音色包导入改为原生流式解压（修复 75MB 音色包导入闪退）
- 导入前清空旧音色包；导入后自动重新加载并显示预热耗时

### 0.3.8

- 支持 Matcha 模型（声学模型 + 声码器）
- 新增 Matcha zh-baker 音色包（标准普通话，RTF≈0.05）

### 0.3.7

- 禁用 WebView 缓存，升级后立即生效
- 设置里显示版本号；`versionName` 与发布号对齐

### 0.3.6

- 音色包：任意 `.onnx` 都能识别，换包时先清空旧文件
- 导入后显示模型预热耗时

### 0.3.5

- 修复点「听」无反应：合成线程与模型加载线程分离

### 0.3.4
