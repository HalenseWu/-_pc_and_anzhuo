# 无涯 · 设计文档

版本对应：桌面版 0.21.0 / 安卓版 0.4.1

---

## 1. 目标与约束

**目标**：一个纯本地、可长期使用的中文小说阅读器，桌面与手机体验一致、数据可互通。

**硬约束**：

1. **不联网**：书籍内容、进度、笔记不出本机；手机版除用户主动下载音色包外无任何网络行为。
2. **格式友好**：TXT 为主（编码/目录混乱的现实），同时支持 EPUB、PDF。
3. **阅读优先**：排版可调，进度精确到页，重启不丢。
4. **两端一致**：同一套解析、分页、锚点、备份格式。

**取舍**：

- 桌面端用 Electron（体积大、但排版引擎与手机 WebView 一致，代码可复制）；
- 手机端用 Capacitor（直接复用 React 页面，原生只做能力补齐：音量键、TTS、启动页）；
- 朗读不追求"真人级"，优先离线与速度，模型可换。

### 线程模型（手机端朗读）

```
JS 主线程            utterance 事件 ←→ 队列推进、高亮、跟随
                      │  speak(id,text) / prefetch(id,text)
原生合成线程          任务队列（urgent 优先 / prefetch 后台）
（wuya-local-tts）     generate() → wav 缓存 → 通知播放
UI 线程                MediaPlayer.reset/setDataSource/start → start/done 事件
前台服务线程           通知栏与锁屏媒体按钮 → mediaAction 事件回 JS
```

关键点：**合成线程独立于模型加载线程**，否则 `prepare()` 会被合成死循环饿死（见踩坑记录 #14）。

## 3. 数据模型

```ts
interface BookMeta {
  id: string            // 源文件 SHA-1，跨端稳定
  title: string; author?: string
  format: 'TXT' | 'EPUB' | 'PDF'
  bytes: number; chars: number
  cover: [string, string]   // 渐变封面
  coverImage?: string       // EPUB/PDF 封面 dataURL
  progress: number          // 0-100
  currentChapterId?: string
  anchor?: ReadAnchor       // 精确阅读位置
  createdAt: number; lastReadAt?: number
}

interface ChapterNode { id: string; title: string; level: number; children?: ChapterNode[] }

interface ReadAnchor { block: number; offset: number; page?: number }
// block = 第几段；page = 分页模式页码（关键修复，见踩坑 #8）

interface ReaderSettings {
  theme, fontId, fontSize, lineHeight, paragraphGap, margin
  mode: 'page' | 'scroll'
  animation: 'none' | 'slide' | 'cover' | 'fade'
  autoPageSec, autoScrollPx, volumeKeys, keepAwake
  ttsRate, ttsFollow, ttsEngine
}
```

存储布局：

| 平台 | 位置 | 说明 |
|---|---|---|
| 桌面 | `%APPDATA%\无涯\` | `library.json`、`books/<id>/{content.txt,toc.json,meta.json,marks.json,notes.json,source.pdf}`、`stats.json`、`tts.json` |
| 手机 | App 私有 `files/` | 同上，经 Capacitor Filesystem（`Directory.Data`）；浏览器开发时退化为 localStorage |

## 4. 导入与解析

### 4.1 编码探测

按 BOM → UTF-8 严格解码 → GB18030 → Big5 → UTF-16 顺序尝试，失败计数最少者胜出。中文网文里 GB18030 与 UTF-8 混用极常见。

### 4.2 清洗

去 BOM、统一换行、合并被硬换行的段落、去掉常见广告行与页眉页脚、压缩连续空行。

### 4.3 目录识别

1. **正则候选**：`第X章/节/回`、`卷X`、`Chapter N`、纯数字标题等；
2. **打分**：行长、是否独占一行、前后空行、编号连续性、位置分布；
3. **动态规划选链**：在候选序列里找"编号递增且长度合理"的最长链，避免把正文里出现的"第X章"误判为标题；
4. 输出「卷 → 章」两级结构，附解析报告（候选数、疑似章节、异常位置）。

人工校正：目录编辑工作台可拆分、合并、改名、设卷、删除，写 sidecar，不动原文件。

### 4.4 EPUB

`container.xml → OPF → spine` 逐项拆章；目录优先 nav，其次 NCX；正文用 DOMParser 取纯文本，图片抽成 dataURL 随书存储；最后落到与 TXT 相同的「章节数组」结构，阅读器无需区分格式。

### 4.5 PDF

pdf.js 渲染原始页面（不重排），保留文字层：可选中、可复制、页内搜索、选中文字记笔记（按页锚点）。宽屏可双页对开。

## 5. 排版与分页

### 5.1 分页实现

用 CSS 多栏排版，而不是手动切字：

```
.rd-flow {
  column-width: <内容宽度>px;   /* = 舞台宽 - 左右边距 */
  column-gap: 48px;
  transform: translateX(-page * (内容宽度 + 48)px);
}
```

- 章节标题作为流内第一个块，保证"每章第一页有标题"；
- 页数 = `round((scrollWidth + gap) / (内容宽度 + gap))`；
- 换字号/行距/字体后重新测量，页码按锚点回算并 clamp 到有效范围；
- **必须等 `document.fonts.ready`** 再测量，否则字体回退会导致页数与位置错乱（踩坑 #2）。

### 5.2 跨章翻页

- 章末右点 → 下一章第 1 页；
- 章首左点 → 上一章**最后一页**（store 里 `goChapter(index, anchor, gotoEnd)`，落位延后一帧再量页数，避免把总页数算成 1）。

### 5.3 锚点还原

保存 `{block, page}`：`page` 优先（跨栏段落用 block 反算会差一页，踩坑 #8），书签/笔记仍用 block。手机端另有「ready 门」：`open()` 完成前不渲染阅读页，避免旧状态抢先消费锚点。

## 6. 滚动模式

- 内容按章节流式渲染（`[data-cid]` 分节），视口顶部所在章节驱动标题与进度；
- 接近底部**且向下滚**时追加下一章；接近顶部**且向上滚**时前置上一章，并用「新增高度差」补偿 `scrollTop`，视觉不跳；
- 跳章（目录、上一/下一章）后 0.9 秒冷却 + 重置滚动基准，避免刚跳章就被判成"到顶"而误补章（踩坑 #6）；
- 滚动模式切回分页：取**视口中心**所在段落映射页码（正好一半时取前一页），保证不漏读。

## 7. 朗读管线

```
章节 → 段落分段（≤88 字，约 5 行）→ 句子切分（≤80 字）
   → 队列 item{chapterId, block, seg, text}
   → 引擎 speak（系统 TTS / 本地 sherpa-onnx）
   → start 事件：预取后 3 句 + 高亮当前段
   → done 事件：推进到下一句（队列空则换章）
```

- **引擎抽象**：`platform/tts.ts` 统一 `init/speak/stop/setRate/onUtterance/onMediaAction`，内部路由系统 TTS 或本地引擎；本地不可用自动回退；
- **预合成**：本地引擎支持 `prefetch`，播放当前句时后台已算好后续 3 句，句间停顿从十几秒降到 0.1–0.4 秒；
- **高亮**：段落切成 ≤5 行的显示片段（`segmentParagraph`），只把当前片段包 `<span class="rd-seg on">`，不改变排版；
- **跟随**：翻页模式按 block 反算页码；滚动模式 `scrollIntoView({block:'center'})`；
- **媒体控制**：前台服务 + `MediaSession`，通知栏三键与蓝牙键统一转成 `mediaAction` 事件。

## 8. 本地 TTS 模型选型

| 模型 | 结构 | 体积 | PC 实测 RTF | 结论 |
|---|---|---|---|---|
| MeloTTS zh_en int8 | VITS | 51 MB + 词典 11 MB | **1.32** | 音质好但太慢，仅作可选 |
| Piper zh_CN-huayan x_low | VITS（轻量） | 19.7 MB | **0.03** | 极快，腔调偏重 |
| Matcha zh-baker + hifigan_v2 | Matcha + 声码器 | 72 MB + 3.6 MB | **0.05** | 标准普通话，推荐 |

工程要点：

- 使用 sherpa-onnx 官方 **Java API**（`com.k2fsa.sherpa.onnx`）编译进 App，JNI 库只保留 `arm64-v8a`；
- 模型目录识别：优先 `model.int8.onnx` / `model.onnx`，否则取任意 `.onnx`；含 `model-steps-3.onnx` + `vocoder.onnx` 时走 Matcha 配置；
- 合成线程数 = `min(4, 核数/2)`；
- 生成结果写 wav 缓存（LRU 12 条），`MediaPlayer` 复用；
- 音色包导入走**原生流式解压**（SAF 选择器 → `ZipInputStream` → 64KB 缓冲），避免 JS 端把 75MB 读进内存。

## 9. 备份格式（.wuya）

标准 zip，改后缀；`manifest.json` 版本号用于向后兼容判断：

```json
{ "app": "wuya", "version": 1, "platform": "android|win32", "createdAt": 0, "books": 3 }
```

合并规则：

- 书籍按 id 去重，已存在跳过（新增 N 本 / 已存在 M 本）；
- 统计按天取 `max`，避免同一份备份导入两次时长翻倍；
- 正文、目录、书签、笔记整目录复制。

## 10. 性能与体积

| 指标 | 数值 |
|---|---|
| 桌面安装包 | 约 90 MB（Electron 运行时） |
| 安卓 APK | 47.9 MB（含 31 MB 推理库） |
| 安卓冷启动 | 启动页 1.5 秒 + WebView 首屏约 0.8 秒 |
| 长篇小说（734 章） | 目录解析 < 1 秒；分页测量单章 < 30 ms |
| 朗读 | Piper/Matcha 合成 RTF 0.03–0.05；预取 3 句 |

内存：本地 TTS 常驻约 250–350 MB（模型 + ONNX 运行时），退出阅读页 5 分钟后卸载。

## 11. 已知限制

1. 安卓版只提供 arm64 构建，未做 x86_64（模拟器无法验证本地朗读）；
2. 目录编辑后写回**扁平**章节表，卷结构会丢失；
3. PDF 不做重排，纯图片型 PDF 无法选字/搜索；
4. 朗读按句合成，跨句韵律不如整段合成自然；
5. 自训音色未打通（GPT-SoVITS 与 sherpa-onnx 模型结构不同，需用同一批语料重新训练 VITS 再导出 ONNX）。
